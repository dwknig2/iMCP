# The Project Manual

**Tagline:** One Manual to Rule Them All

A native iOS project companion for hands-on build projects. Phase 1 Swift source lives in [`TheProjectManual/`](TheProjectManual/).

## Status

Phase 1 delivers SwiftUI + SwiftData source for the vertical slice (project list, next-step mode, verification gates, measurements, sample workbench fixture, and unit tests). **Create the Xcode project on macOS** — see [`TheProjectManual/README.md`](TheProjectManual/README.md) for setup steps.

## Requires macOS / Xcode

Build, run, preview, and test validation must be performed locally in Xcode. This repository intentionally does not include a hand-generated `.xcodeproj`.
